# NumPy и Pandas

- `task_1_numpy.ipynb` — массивы.
- `task_2_tensor.ipynb` — тензор.
- `tasks_3_4_pandas.ipynb` — очистка и анализ CSV.

## Запуск

Python 3.9–3.12:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
jupyter lab
```

Windows: активация `.venv\Scripts\activate`.

Откройте нужный Notebook → **Restart Kernel → Run All**.
Для Tasks 3–4 нужен `listings.csv` рядом; `apartments_clean.csv` создаётся автоматически. После установки библиотек интернет не нужен.
